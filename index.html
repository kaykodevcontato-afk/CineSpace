Sobre o Arcoverde Bus

O Arcoverde Bus é um protótipo acadêmico de um sistema web para visualização de transporte.

🎯 Objetivo

Demonstrar como tecnologias web podem ser utilizadas para criar uma interface de acompanhamento de transporte.

🛠️ Tecnologias

  • HTML5
  • CSS3
  • JavaScript
  • Leaflet
  • OpenStreetMap
  • OSRM

⚠️ Observação

Este sistema é uma demonstração acadêmica. Os dados de rotas e pontos não devem ser considerados informações oficiais.
