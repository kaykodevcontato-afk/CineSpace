Sobre o projeto

O Arcoverde Bus é um protótipo acadêmico desenvolvido para demonstrar a aplicação de tecnologias web em um sistema de transporte.

🎯 Objetivo

Criar uma interface para visualizar linhas, ônibus, escolas, bairros e paradas.

🛠️ Tecnologias

HTML • CSS • JavaScript • Leaflet • OpenStreetMap • OSRM

Projeto demonstrativo.
